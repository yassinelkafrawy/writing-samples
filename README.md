# Medical Writing & Clinical Research Samples

A static portfolio of three work samples for medical writing and clinical research roles. It includes a clinician-facing evidence review, a fictional Phase II protocol synopsis, and a fictional case report. Each sample has an independent reference list and a print-friendly layout.

[View the portfolio](https://yassinelkafrawy.github.io/writing-samples/)

## Samples

2. [A Randomized Phase II Trial of Dexamethasone De-escalation During Elotuzumab–Pomalidomide Therapy in Relapsed or Refractory Multiple Myeloma](https://yassinelkafrawy.github.io/writing-samples/#protocol-synopsis)
3. [Severe Isolated Thrombocytopenia With Mucocutaneous Bleeding in an Adult: A Fictional Case Report](https://yassinelkafrawy.github.io/writing-samples/#case-report)

## Standards

- ICH GCP E6(R3) principles and Annex 1 inform the fictional protocol synopsis.
- CARE guidelines guide the structure of the fictional case report.
- Vancouver referencing is used across the three samples.

## Local preview and PDF export

Open `index.html` in a browser. Select **Download PDFs**, choose a sample, then use **Save as PDF** in the print dialog. To offer a direct download, place the exported PDF in `assets/` and add a link such as `<a href="assets/evidence-review.pdf" download>Download evidence review PDF</a>` to the sample's download row.

## Publishing

Publish the repository's `main` branch from `/(root)` in **Settings → Pages**. The site uses plain HTML, CSS, and JavaScript.
